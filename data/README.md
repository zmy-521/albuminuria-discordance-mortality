# Data access

No individual-level data are distributed. Obtain NHANES XPT/codebooks and the **2019** public mortality linkage from CDC. Do not silently substitute a newer mortality release. Follow `docs/REPRODUCIBILITY.md` for local layout.

Hospital LIS records, dates, identifiers, linkage bridges, salts, raw audits and derived records require institutional authorization and protected storage. The same restrictions apply to model objects and anonymous patient plotting CSVs. Removing names does not establish publication permission.

`.gitignore` only guards accidental Git inclusion; it does not protect browser uploads or already-tracked files. Inspect archives before uploading.
