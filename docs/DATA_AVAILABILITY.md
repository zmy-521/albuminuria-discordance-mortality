# Data and code availability

Public NHANES data/codebooks:
- https://wwwn.cdc.gov/nchs/nhanes/search/datapage.aspx?Component=Laboratory
- https://wwwn.cdc.gov/nchs/nhanes/
- https://www.cdc.gov/nchs/linked-data/mortality-files/

The workflow uses the official **2019** mortality release, not an automatically selected latest release. Users obtain originals from CDC under applicable terms. Public raw databases are not redistributed here.

Wanbei hospital records are confidential and require institutional authorization. Code is supplied for transparency; this component cannot be reproduced solely from public materials. No guarantee of access is made. Included result files are reviewed aggregates or coefficient/covariance summaries only. No fitted objects, clinical records, ethics files, internal conversations or manuscript drafts are distributed. No license has been selected.

## Manuscript wording — author to add repository location after deposition

NHANES data and the 2019 public-use linked mortality files are available from the US National Center for Health Statistics. The analysis and figure-generation code will be made available in an author-managed public repository; its location will be added upon deposition. Hospital participant-level data are not publicly available because of patient confidentiality and institutional restrictions. The code release documents the data requirements for this component but does not enable complete reproduction of the hospital analyses without authorized access. Provenance and reproducibility documentation accompany the code; an independent end-to-end rerun of the entire study was not performed during release preparation.
