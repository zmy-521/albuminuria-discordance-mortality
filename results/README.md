# Public aggregate inputs

Only frozen cells consumed by approved main-figure renderers were copied. Header row 4 and original row coordinates are preserved; other cells/sheets are absent. These reduced files do not replace the full frozen workbooks. Source/release hashes are in the manifest. No values were recomputed.

The component CSVs contain regression coefficients and design covariance, not observations. `period_interaction.json` preserves the original renderer's rounded P=0.17983. Internal handoff prose is excluded.

Supplementary sensitivity/A2 rendering functions are included as source, but their additional aggregate rows must be supplied before use. This directory does not claim complete supplementary plotting dependencies.
